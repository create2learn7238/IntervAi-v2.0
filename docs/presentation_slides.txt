================================================================================
                               INTERVAI
          Intelligent Mock-Interview & Candidate Evaluation Platform
================================================================================

Main Idea: Bridge the gap between candidate preparation and real-world 
technical interviews using dynamic AI generation and live proctoring.


================================================================================
                     SLIDE 2: PROBLEM STATEMENT & OBJECTIVES
================================================================================

PROBLEM STATEMENT:
- Traditional mock interviews use static, easily memorized question banks.
- Difficulty in objectively evaluating a candidate's spoken communication 
  and technical depth remotely.
- Remote interviews lack integrity and are highly prone to cheating.

OBJECTIVES:
- Create an automated, dynamic AI interviewer that generates unique 
  questions per candidate.
- Analyze real-time speech to evaluate technical correctness, vocabulary, 
  and problem-solving skills.
- Protect interview integrity with an automated computer vision 
  Trust Score system.


================================================================================
                             SLIDE 3: MAIN MODULES
================================================================================

- USERS: Secure login, registration, and personalized candidate 
  onboarding profiles.
- AI ENGINE: Dynamic technical question generation and real-time answer 
  evaluation using Google Gemini.
- LIVE PROCTORING: Browser behavior tracking and facial recognition 
  computer vision.
- ANALYTICS: Candidate dashboards with AI-driven personalized feedback 
  and improvement areas.
- RECRUITER PORTAL: Aggregated candidate scoreboards and automated hiring 
  recommendations.


================================================================================
                           SLIDE 4: HOW INTERVAI WORKS
================================================================================

1. Candidate creates a secure profile detailing their target role and skills.
2. Candidate initiates a new mock interview session.
3. System prompts Gemini AI to generate a unique technical question based 
   on the candidate's exact profile.
4. Candidate answers via microphone; speech is converted to text in real-time.
5. AI evaluates the transcribed answer for technical depth, clarity, and pace.
6. Background proctoring monitors tab-switches and facial presence to 
   calculate a Trust Score.
7. IntervAI generates a final Readiness Percentage and personalized weaknesses.
8. Recruiters view the aggregated insights to make hiring decisions 
   (Reject / Consider / Hire).


================================================================================
                            SLIDE 5: TECHNOLOGY STACK
================================================================================

- Programming Language: JavaScript
- Frontend Framework: React.js, Tailwind CSS, Framer Motion
- Backend Framework: Node.js, Express.js
- Database: MongoDB (with Mongoose ODM)
- API Security: JSON Web Tokens (JWT) & bcryptjs
- AI Integration: Google Gemini API (@google/generative-ai)
- Live Proctoring: MediaPipe Tasks Vision (Machine Learning)
- Audio Processing: React Speech Recognition


================================================================================
                             SLIDE 6: DATABASE SYSTEM
================================================================================

The MongoDB database stores important information such as:

- USERS: Applicant profiles, credentials, and settings.
- INTERVIEWS: Session tracking, target roles, and timestamps.
- USER ANSWERS: Spoken transcripts, AI ratings (0-10), and detailed feedback.
- TRUST SCORES: Logs of proctoring violations (e.g., looking away, tab 
  switching).
- CANDIDATE AI PROFILES: AI-summarized strengths, weaknesses, and 
  recommended roles.
- CERTIFICATES: Downloadable PDF completion records.


================================================================================
                      SLIDE 7: EVALUATION & SCORING SYSTEM
================================================================================

OVERALL READINESS CALCULATION
IntervAI calculates a candidate's true suitability by evaluating multiple 
dimensions simultaneously. This gives a much more complete evaluation than 
just checking if an answer is technically correct.

- AI SCORE (Technical Depth & Correctness): Generated by comparing the 
  transcript against an Ideal Answer Key.
- SPEECH METRICS (Clarity, Pace, Vocabulary): Evaluated based on the 
  fluency of the spoken text.
- TRUST SCORE (Integrity): Starts at 100%. Deducts points for camera off 
  (-15), tab switching (-5), or multiple faces detected (-20).


================================================================================
                               SLIDE 8: ADVANTAGES
================================================================================

- Replaces easily memorized question banks with infinitely unique, 
  AI-generated questions.
- Provides holistic, objective grading based on both technical knowledge 
  and communication skills.
- Secures remote interview integrity without requiring a human proctor.
- Saves recruiter time by automatically summarizing candidate strengths 
  and weaknesses.
- Provides candidates with actionable, targeted feedback to improve 
  their interview skills.
